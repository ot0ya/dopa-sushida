# ドパ寿司打

寿司が流れてくるタイピングゲームです。ネオンと祭りをごちゃ混ぜにして、ドパドパ感を足しました。ブラウザだけで動きます（インストール不要）。

**▶ 遊ぶ：https://ot0ya.github.io/dopa-sushida/**

## 遊び方
- `1` `2` `3` でコース（梅・竹・松）を選び、`Enter` か `Space` で開始します。
- 寿司が左へ流れきる前に、お題をローマ字で打ち切ります。流れた言葉は失敗ですが、コンボは続きます。ミスタイプするとコンボが切れます。
- 10コンボごとに倍率が上がります（最大×5）。30コンボで「大トロFEVER」になり、得点が2倍になります。
- 結果画面に、12段階のランク（皿洗い〜寿司神）が出ます。寿司神の目安は、毎秒約7打鍵（ミス率3%）です。
- `M` でミュート、`Esc` でタイトルに戻ります。キーが反応しないときは、画面を一度クリックしてください。

## 作り方（開発者向け）
| ファイル | 役割 |
|---|---|
| `index.html` | ビルド済みの完成品（これだけで動く） |
| `src/game.template.html` | ゲーム本体（HTML/CSS/JS） |
| `src/words.js` | お題リスト（梅・竹・松） |
| `build.py` | 画像とお題を埋め込んで `index.html` を作る |
| `check_words.js` | お題がすべて打てる形か検証する |
| `calibrate_rank.js` | ランクの基準点を、打鍵速度の試算から出す |
| `check_music.js` | BGMの構成を、音を出さずに点検する |
| `追加素材/` | 追加した寿司イラストと、その作り方（プロンプト集・背景透過スクリプト） |

`build.py` は、元の寿司GIFのzipを読み込む前提です。zipは公開していないので、`index.html` を直接編集するか、`src/` を編集して手元で `build.py` を調整してください。

## 素材について
- **寿司イラスト24枚**（`追加素材/out/`）は、Gemini で生成した画像の背景を透過したものです。
- **元の寿司GIF（45枚）** は、出どころが分かっていません。`index.html` に埋め込まれています。権利をお持ちの方から連絡があれば、すぐに差し替え・削除します。
- 効果音とBGMは、Web Audio API でコード上で合成しています。音声ファイルは使っていません。
