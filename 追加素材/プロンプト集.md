# ドパ寿司打 追加素材プロンプト集

## 使い方（毎回これを守る）
1. 画像生成AI（ChatGPT / Gemini）に、`参考画像/` の **参考1・参考3・参考4 の3枚を毎回添付**する。
2. 下の **【固定スタイル】を丸ごと貼る**（省略しない・言い換えない）。
3. その下に **【今回の被写体】を1つだけ**貼る。1回の生成で描くのは1点だけ。
4. 絵柄がズレたら、作り直さずに「参考画像と比べて◯◯が違う。参考画像に合わせて描き直して」と指示する。
5. 保存名は下のリストの **ファイル名**（例：`hotate.png`）にする。保存先は `追加素材/` フォルダ。

## 【固定スタイル】（毎回ここから ここまで を貼る）
```
回転寿司ゲーム用のアイテム素材イラストを「1点だけ」描いてください。
添付した参考画像と、同じ画風・同じ視点・同じ質感・同じ彩度で描いてください。

- 画風：光沢のある半リアル調のイラスト。やわらかいグラデーションで立体的に塗る。黒い輪郭線（縁取り）は描かない。ネタの表面に小さな白いハイライトを入れる。写真ではなく、フラットなベタ塗りでもない。参考画像と同じ「きれいなアイコン風イラスト」。
- 視点：正面からやや上（俯角およそ30度）の斜め前。握り寿司は長辺を画面の左右に向け、右側がほんの少し上がるように10〜15度傾ける。
- 構図：被写体は画面中央に1点のみ。キャンバスの横幅の約75%の大きさ。周囲に余白をとり、見切れさせない。
- 色：明るく鮮やかで、彩度はやや高め。シャリは真っ白にせず、ごく薄いグレーの陰影と米粒の質感で立体的に描く。海苔は艶のある黒に近い濃い緑。
- 光：左上から柔らかい光。右下に向かって穏やかな陰。
- 影：被写体のすぐ下に、ごく薄いグレーの接地影だけ。背景には影を落とさない。
- 背景：蛍光グリーン（#00FF00）のべた塗り一色。グラデーション・模様・テーブル・光のにじみは入れない。
- サイズ：横長 3:2（1536×1024）。
- 描かないもの：皿・お盆・まな板・箸・手・人物・文字・ロゴ・枠・透かし。指定された被写体以外は何も描かない。
```
